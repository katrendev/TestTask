# Тестовое задание — C# / Анализ символов из файлов

Программа принимает два текстовых файла:  
- в первом анализируются одиночные буквы (с учётом регистра);  
- во втором — повторяющиеся одинаковые буквы (без учёта регистра, например "АА" или "оо").  

Реализована фильтрация:  
- из первого файла удаляются гласные;  
- из второго — согласные.  

В конце выводится отсортировка и общее количество найденных символов.

---

- Проект собран под .NET 6  
- Запускается в Visual Studio 2022+
